How it works

Program rules and courses come from York's public calendar data (one version per calendar year). A rules engine, not the AI, decides whether each requirement is met. Free-text rules (electives, "outside the major", breadth) are read by an interpreter; anything it doesn't understand is marked ask an advisor instead of guessed.
